# Electric Vehicle Market Analysis Using Power BI

## 📌 Project Overview

This project focuses on analyzing **Electric Vehicle (EV) Population data** using **Microsoft Power BI**. The main objective is to understand the growth of electric vehicle adoption, identify popular manufacturers and models, and explore market trends through interactive dashboards.

The project provides insights into EV registration patterns, vehicle types, geographic distribution, electric driving range, and Clean Alternative Fuel Vehicle (CAFV) eligibility.

## 🎯 Objectives

- Analyze electric vehicle registration trends over time.
- Identify the top manufacturers and popular EV models.
- Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Explore EV distribution across different cities and counties.
- Analyze electric driving range across vehicle models.
- Understand CAFV eligibility patterns.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard creation and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculations and measures.
- **Data Modeling** – Organizing data for effective analysis.

## 🧹 Data Preparation

- Handled missing values in important columns.
- Removed duplicate records where applicable.
- Replaced missing numerical values using median imputation.
- Standardized categorical values.
- Prepared the dataset for visualization and analysis.

## 📊 Dashboards

1. **EV Market & Manufacturer Overview**
2. **Geographic Distribution**
3. **Electric Technology & Electric Range**
4. **CAFV Eligibility & Electric Utilities**

## 💡 Key Outcomes

- Identified leading EV manufacturers and popular models.
- Explored EV adoption trends over different years.
- Compared BEV and PHEV market distribution.
- Analyzed geographical patterns in EV registrations.
- Examined electric range and CAFV eligibility.

## 📝 Conclusion

This project demonstrates how Power BI can transform raw electric vehicle population data into interactive dashboards and meaningful insights. It provides a better understanding of EV market trends, vehicle preferences, and adoption patterns through data visualization.
